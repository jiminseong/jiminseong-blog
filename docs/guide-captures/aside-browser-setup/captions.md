## 비고

- **AS-01/03/04/08/09는 실제 화면 촬영이지만, 설정·온보딩 화면(AS-03/04/09)은
  실제 사이드패널이 아니라 같은 UI를 일반 탭에서 다시 그린 것이다.**
  Aside 설정 UI는 번들 컴포넌트 확장(`Aside Browsing Agent`)의 웹 페이지라
  `chrome-extension://<확장ID>/sidepanel.html#/<라우트>` 를 탭으로 열어 렌더했다.
  데이터는 실제 계정의 실제 설정값이지만, 브라우저 창에 붙어 있는 사이드패널을
  픽셀 그대로 캡처한 것은 아니다.
- **AS-02는 촬영이 아니라 HTML 재현이다.** dmg 창은 브라우저 밖 macOS Finder
  화면이라 캡처 경로가 없다. 실제 Aside 앱 아이콘(`Aside.app/Contents/Resources/
  app.icns`)과 macOS 기본 Applications 폴더 아이콘을 추출해 HTML로 재구성했다.
- AS-08의 배송지·연락처·배송 요청(도어코드)·계좌번호·현금영수증 영역은
  단색 박스로 덮었다. 결제 버튼은 누르지 않았다.
- **AS-07은 사용자가 macOS에서 직접 찍은 스크린샷을 가공한 것이다.** 이 화면은
  macOS 메뉴바 + 브라우저 사이드바 + 탭 + 사이드패널이 한 창에 붙어 있어
  에이전트가 캡처할 수 있는 경로가 없다(아래 차이보고 참조). 원본 2880×1800을
  1440×900으로 축소하고, 쿠팡 계정명과 진행 중인 다른 작업의 채팅 제목(외부
  클라이언트 건)을 단색 박스로 덮은 뒤 ①②③ 번호를 얹었다.
- **AS-05는 `Connect` 드롭다운을 연 상태로 찍었다.** 닫힌 상태의 Providers 목록에는
  ChatGPT 행이 없기 때문이다(차이보고 참조). 드롭다운은 열기만 했고 아무 항목도
  선택하지 않았다.
- **AS-06은 프롬프트를 입력만 하고 실행하지 않은 상태다.** 전송 버튼은 누르지 않았고,
  캡처 후 입력 내용은 지웠다.
- **AS-07-plain.png는 커버용이다.** AS-07과 동일한 마스킹을 유지한 채 ①②③ 번호와
  빨간 테두리만 뺐고, 해상도는 원본 2880×1800 그대로다.
- 규격: AS-07-plain을 제외한 전부 1440×900 PNG. 강조는 #E5484D 3px 테두리, 복수일 때 ①② 번호.
- 라이트 모드는 설정 변경 없이 렌더된 페이지의 DOM 클래스(`dark`→`light`)만
  바꿔서 적용했다. 저장된 설정값은 건드리지 않았다.
