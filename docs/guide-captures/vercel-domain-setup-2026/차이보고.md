# 차이 보고

샷 리스트에 적힌 설명과 2026-09-13 기준 실제 화면이 달랐던 항목입니다.
형식: **샷 번호 / 설명에 적힌 것 / 실제 화면**

## A. 본문 내용을 반드시 고쳐야 하는 항목

### 11 / "Nameservers 탭에 ns1·ns2 두 줄" / Vercel은 네임서버가 아니라 **A 레코드 한 줄**을 안내함
- 이 글의 전제가 바뀌는 가장 큰 차이입니다.
- 현재 Vercel 프로젝트 Domains 화면에서 도메인 카드를 펼치면
  `Type: A / Name: @ / Value: 216.198.79.1` 한 줄만 나옵니다. Nameservers 탭 자체가 없습니다.
- 안내 문구: "We're expanding our IP range. The legacy records cname.vercel-dns.com and
  76.76.21.21 will continue to work."
- 네임서버 방식(ns1.vercel-dns.com / ns2.vercel-dns.com)은 Vercel 공식 문서에는 여전히 존재하지만,
  대시보드 화면에서는 **Vercel DNS를 활성화(Enable Vercel DNS)해야만** 값이 노출됩니다.
  그건 실제 DNS 변경 작업이라 규칙 2에 따라 누르지 않았습니다.
- 11.png 는 실제 화면대로 A 레코드 행과 복사 아이콘 2개를 찍은 것입니다.
- **권고**: 본문을 "네임서버 붙여넣기" 대신 "A 레코드 붙여넣기(가비아 DNS 호스트)"로 바꾸거나,
  네임서버 방식과 A 레코드 방식을 둘 다 설명하는 구조로 바꾸는 게 맞습니다.
  3부 제목 "가비아에 붙여넣기"도 영향을 받습니다.

### 18 / "주소창 자물쇠" / 크롬에는 자물쇠가 없고 **튠(슬라이더) 아이콘**
- 크롬 117부터 주소창의 자물쇠가 "튠(tune)" 아이콘으로 대체됐습니다.
  (출처: Chromium 공식 블로그 "An Update on the Lock Icon", 2023-05)
- 이 작업에 쓴 브라우저는 Chrome 152 이고, 실제로 자물쇠가 아니라 튠 아이콘이 표시됩니다.
- **권고**: "자물쇠 아이콘" 표현을 "주소창 왼쪽의 사이트 정보 아이콘"으로 바꾸세요.
  독자가 자물쇠를 찾다가 못 찾습니다.

### 07 / "상단 Settings 탭 → 사이드바 Domains" / 상단 탭 없음, Domains가 **왼쪽 사이드바 독립 항목**
- 현재 Vercel 프로젝트 화면은 상단 탭 바가 없고 전부 왼쪽 사이드바입니다.
- Domains 는 Settings 안이 아니라 사이드바 최상위 항목입니다.
  (Overview / Deployments / ... / Environment Variables / **Domains** / Connect / ... / Settings)
- Settings 는 사이드바 맨 아래 별도 항목입니다.
- 07.png 는 ① 사이드바 Domains ② 사이드바 Settings 로 찍었습니다.
- **권고**: "Settings 탭을 누르고 사이드바에서 Domains" → "왼쪽 메뉴에서 Domains를 바로 클릭"으로 수정.

## B. 버튼 이름·단계 구성이 달라진 항목

### 03 / "신청하기 버튼" / 각 행의 버튼 이름은 **선택**
- "신청하기"는 오른쪽 장바구니 패널 하단에 있는 별개 버튼입니다.
- 흐름: 행의 `선택` → 오른쪽 장바구니에 담김 → 장바구니의 `신청하기`.

### 04 / "장바구니 화면의 결제하기 버튼" / **별도 장바구니 페이지가 없음**
- 검색 결과 페이지 오른쪽에 "도메인 장바구니" 패널이 붙어 있고, 버튼 이름은 `신청하기` 입니다.
- `결제하기` 라는 버튼은 이 흐름에 없습니다.
- 04.png 는 이 패널의 `신청하기` 버튼을 찍었습니다.

### 05 / "결제 옵션 화면 / 부가 서비스 체크박스" / 화면 이름은 **신청 정보 입력**, 부가서비스는 **토글 스위치**
- 단계 표시는 `1 신청 정보 입력 → 2 서비스 비용 결제 → 3 정보 확인` 입니다.
- 등록 기간 기본값은 **3년** 입니다(1년 아님). 1년으로 바꿔서 찍었습니다.
- 부가 서비스는 체크박스가 아니라 `안전잠금` 토글 1개이고, 기본값이 이미 꺼짐(무료)입니다.

### 09 / "www 리다이렉트 안내 화면에서 Yes 선택" / **별도 화면이 아니라 같은 팝업 안의 체크박스**
- Add Domains 팝업 안에 `Redirect apex domains to www (recommended)` 체크박스가 있고,
  **기본값이 이미 체크됨** 입니다. Yes/No 를 고르는 별도 단계는 없습니다.
- 09.png 는 그 체크박스를 강조해서 찍었습니다.

### 08 / "Add Domain 팝업" / 버튼 이름은 **Add Existing**, 팝업 제목은 **Add Domains**
- Domains 화면 오른쪽 위 버튼이 `Add Existing` 과 `Buy` 두 개입니다.
- 팝업 제목은 `Add Domains`(복수), 하단 버튼은 도메인 입력 전 `Add 0 Domains`(비활성),
  입력 후 `Add Domain` 으로 바뀝니다.

### 10 / "빨간 Invalid Configuration" / 실제는 **주황색 DNS Change Recommended**
- 빨간 Invalid Configuration 은 도메인이 아예 연결되지 않았을 때만 나옵니다.
- 이미 잘 붙어 있고 Vercel이 권장 IP만 바꾸라고 안내하는 상태라 주황색 경고로 표시됩니다.
- "Nameservers 탭" 대신 `View DNS configuration` 펼치기 링크가 그 자리를 대신합니다.

### 13 / "① 서비스 관리 ② 도메인 ③ 관리 버튼" / ②는 메뉴가 아니라 **서비스 종류 선택 드롭다운**
- 도메인만 따로 있는 메뉴는 없고, 목록 위 드롭다운에서 `전체 서비스 → 도메인` 을 고르는 방식입니다.
- 13.png 는 그 드롭다운을 ②로 찍었고, 다른 도메인이 노출되지 않도록 검색창에 해당 도메인을 넣어
  1건만 남긴 상태로 찍었습니다.

### 14 / "도메인 정보 페이지의 네임서버 항목 옆 설정 버튼" / **탭을 한 번 더 눌러야 함**
- `관리` 를 누르면 새 창(domains.gabia.com)이 열리고, 기본 탭은 `도메인 정보` 입니다.
- 네임서버 설정 버튼은 `네임서버/DNS호스트/DNSSEC` 탭 안에 있습니다.
- 14.png 는 그 탭을 누른 뒤의 `네임 서버 · 설정` 버튼입니다.
- **권고**: 본문에 "네임서버/DNS호스트/DNSSEC 탭을 먼저 누른다"는 단계를 하나 추가해야 합니다.

### 15 / "1·2차 입력하고 3·4차는 비움" / 기본 칸은 **3개까지만**, 4차는 `+ 추가` 를 눌러야 생김
- 팝업 제목은 `네임서버 변경` 입니다.
- 기본값으로 1차 ns.gabia.co.kr / 2차 ns1.gabia.co.kr / 3차 ns.gabia.net 이 이미 들어 있어서,
  **3차는 비우는 게 아니라 기존 값을 지워야 합니다.**
- 팝업 위쪽에 `네임서버` / `가비아 네임서버` 라디오 선택이 따로 있습니다.

### 16 / "소유자 인증 버튼과 적용 버튼" / 소유자 인증은 **버튼이 아니라 휴대전화·이메일 라디오 선택**
- 인증 수단을 고르기 전에는 `적용` 버튼이 **비활성 상태** 입니다.
- 하단 버튼은 `뒤로` / `적용` / `취소` 세 개입니다.

### 17 / "Valid Configuration 초록 체크" / 커스텀 도메인은 여전히 **주황 경고**, 초록 체크는 .vercel.app 쪽
- 10번과 같은 이유입니다. 사이트는 정상 동작하지만 Vercel이 권장 IP 변경을 안내 중이라
  jiminseong.com / www.jiminseong.com 둘 다 `DNS Change Recommended` 입니다.
- `Valid Configuration` + 체크 표시는 jiminseong-blog.vercel.app 행에만 있고,
  체크 색은 초록이 아니라 **파랑** 입니다.
- 17.png 는 ① jiminseong.com 행의 Refresh ② 실제로 존재하는 Valid Configuration 표시로 찍었습니다.

### 01 / "카카오·네이버 간편 로그인" / **구글 로그인도 함께 있음**
- 화면상 배치는 왼쪽부터 `구글 로그인` → `네이버 로그인` → `카카오 로그인` 입니다.
- 번호는 샷 리스트에 적힌 순서대로 ① 카카오 ② 네이버 로 달았습니다.
  본문에서 왼쪽부터 읽게 쓰실 거면 번호 순서를 바꿔 드릴 수 있습니다.

## C. 촬영하지 못한 샷

### 06 / 결제 수단 선택 화면 / **결제 단계 진입이 막혀서 촬영 불가**
- `다음 단계` 를 누르면 아래 항목이 모두 필수라 통과되지 않습니다.
  - 소유자명(영문) 필수 입력
  - **소유자 이메일 인증 필요** (인증 메일 발송 → 메일함에서 링크 클릭)
  - 전화번호 / 우편번호 / 한글 주소 / 영문 주소 필수 입력
- 저장된 `소유자 목록 → 회원정보` 를 불러와도 영문명·주소는 채워지지 않았습니다.
- 규칙 6에 따라 2회 시도 후 중단했습니다. 미결제 주문서도 생성되지 않았습니다.
- **대안**: 이 화면은 직접 한 번 진행해 보시면서 찍으시거나,
  본문에서 "결제 수단을 고르고 결제하면 끝" 정도로 글로만 설명하는 방법이 있습니다.

## D. 촬영 규격 관련 참고

- **1440 x 900 / 100% 배율**: 충족했습니다. 실제 뷰포트가 1440x900 인 탭에서 촬영했습니다.
- **라이트 모드**: Vercel이 시스템 설정을 따라 다크 모드였어서, Vercel 계정 설정의
  Theme 을 `System` → `Light` 로 바꿔서 촬영했습니다. 원복이 필요하시면 말씀 주세요.
- **크롭**: `확대` 표시가 있는 11·12·18 만 잘랐습니다. 나머지는 전체 창입니다.
  다만 12번(My가비아 버튼)은 버튼 자체가 82x22px 라, 버튼 하나만 60% 이상 차지하게 자르면
  주변 맥락이 사라져 알아볼 수 없게 됩니다. 그래서 상단 우측 메뉴 영역 전체를 약 5.5배로 확대해
  버튼이 크게 보이도록 잘랐습니다.
- **단색 마스킹**: 이름, 팀 이름(jiminseong's projects), 배포 URL의 팀 슬러그,
  "by jiminseong" 작성자 표기를 단색 박스로 덮었습니다.
  다른 도메인은 13번에서 검색 필터로 애초에 화면에 나오지 않게 처리했습니다.
- **18번**: 브라우저 주소창은 웹페이지 영역 밖이라 캡처 도구로 찍히지 않고,
  macOS 화면 기록 권한도 없어 OS 캡처도 불가했습니다. 요청하신 대로 HTML로 주소창을 재현하고
  내부 페이지 영역에는 **실제 www.jiminseong.com 스크린샷**을 넣어 합성했습니다.
  주소창 부분은 실제 촬영본이 아닙니다.

## E. 안 건드린 것 (확인용)

- 실제 결제: 하지 않았습니다. 도메인은 구매되지 않았고 미결제 주문서도 생기지 않았습니다.
- 네임서버: 입력만 하고 `취소` 로 닫았습니다. 촬영 후 페이지를 새로고침해 확인한 결과
  jiminseong.com 의 네임서버는 그대로 `1차 ns.gabia.co.kr / 2차 ns1.gabia.co.kr / 3차 ns.gabia.net` 입니다.
- Vercel 도메인: `Add Domain` 을 누르지 않았고, 팝업은 `Cancel` 로 닫았습니다.
- 가비아 장바구니: 촬영용으로 담았던 mysite-guide-2026.com 은 검색 세션용 임시 담기라
  결제·주문으로 이어지지 않습니다.
- 가비아 계정은 01번 촬영을 위해 **로그아웃된 상태** 입니다. 다시 로그인하셔야 합니다.
