## 비고

- `06.png` 는 촬영하지 못했습니다. 사유는 차이 보고 참고.
- `18.png` 는 브라우저 주소창이 웹페이지 영역 밖이라 캡처 도구로 찍을 수 없어,
  실제 사이트 스크린샷을 안에 넣고 크롬 주소창을 HTML로 재현해 만든 이미지입니다.
  실제 촬영본이 아니라는 점을 본문에 밝히거나, 직접 찍은 스크린샷으로 교체하는 것을 권합니다.
- `cover.png` 는 이번 작업 이전부터 폴더에 있던 파일로, 건드리지 않았습니다.
- `15.png` · `16.png` 의 TXT 레코드는 **줄은 그대로 두고 값만** 단색 박스로 덮었습니다.
  타입 `TXT` · 호스트 `@` · TTL `600` 은 보입니다.
- `16.png` 는 기존 줄을 고치는 화면이 아니라 **`+ 레코드 추가` 로 생긴 빈 줄**에
  `A / @ / 216.198.79.1` 을 입력만 한 상태입니다. 저장하지 않고 취소로 닫았습니다.
- 네임서버 방식으로 찍었던 이전 14·15·16 은 지우지 않고 이름만 바꿔 보관했습니다.
  클라우드플레어 편이나 네임서버 편에서 재사용하시면 됩니다.

  - `ns-02.png` | 가비아 네임서버 변경 팝업 - 1차 입력칸과 2차 입력칸
  - `ns-03.png` | 가비아 네임서버 변경 팝업 하단 - 소유자 인증 선택과 적용 버튼
