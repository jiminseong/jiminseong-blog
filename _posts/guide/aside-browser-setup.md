"AI가 대신 클릭해 준다"는 말을 들으면 뭔가 복잡한 설정이 떠오르죠. 이 글은 그 반대예요.

- 설치하고 계정 만들고 브라우저 데이터 가져오면 준비 끝이에요.
- 첫 작업으로 **쿠팡에서 물건 하나를 골라 결제 직전까지** 맡겨 봅니다.
- 준비 포함 20분, 두 번째부터는 문장 하나 붙여넣기예요.

이 글의 주소는 `jiminseong.com/guide/aside-browser-setup` 입니다. 설정 순서는 Aside 공식 도움말을 기준으로 썼고, 화면은 전부 제 실제 계정에서 찍었어요. 다만 설정과 온보딩 화면은 같은 UI를 탭에서 다시 그려 찍은 것이고, 설치 창 한 장은 재현 이미지예요. 그 부분은 각 그림 아래에 밝혀 두었습니다.

# Aside가 뭔가요?

한 줄로 말하면 **AI가 대신 쓰는 브라우저**예요.

지금까지의 AI는 이랬어요.

- 내가 화면을 보고, 내가 클릭하고, 막히면 AI에게 물어봤어요.
- AI는 조언만 해 주고 클릭은 못 했어요.

Aside는 이 관계가 뒤집혀요.

- 내가 할 일을 문장으로 말해요.
- AI가 브라우저를 직접 열고 클릭해요.
- 나는 결과만 확인해요.

**핵심은 "로그인 상태"예요.** 보통의 AI는 내 쿠팡 계정에 들어갈 수 없어요. Aside는 내가 평소 쓰는 브라우저의 쿠키를 그대로 물려받아서, 이미 로그인된 상태로 일을 시작해요. 그래서 공개 API가 없는 국내 사이트도 자동화가 됩니다.

비유하면 이래요.

- 기존 AI는 전화로 길 알려 주는 친구예요.
- Aside는 조수석에 앉아 직접 운전대를 잡는 친구예요.

Y Combinator 투자를 받은 한국인 창업팀이 만들었고, 브라우저 에이전트 벤치마크 1위를 주장하고 있어요. 다만 이 순위는 자체 측정 기준이라는 점은 알아 두세요.

# 시작 전에 확인할 것

| 항목 | 필요한 것 |
|---|---|
| 운영체제 | **macOS 15.0 이상**. 윈도우는 아직 개발 중이에요. |
| Aside 계정 | 필수예요. 첫 실행 때 만들면 됩니다. |
| AI 구독 | 없어도 돼요. 무료 플랜의 기본 모델로 시작할 수 있고, ChatGPT나 Claude 구독이 있으면 연결하면 돼요. |
| 쿠팡 계정 | 평소 쓰는 브라우저에 로그인되어 있으면 좋아요. |
| 결제 수단 | 결제는 **제가 직접** 합니다. Aside는 결제 직전에 멈춰요. |

화면은 전부 **영어**예요. 한국어 UI는 아직 없지만, 눌러야 할 버튼이 몇 개 안 되니 그림만 보고 따라오셔도 됩니다.

윈도우를 쓰신다면 아직 Aside는 못 써요. 같은 일을 GPT로 하는 방법은 별도 글로 준비하고 있습니다.

# 1부. 설치하고 계정 만들기

## 1단계. 내려받기

- `aside.com`에 접속해 **Download for macOS**를 눌러요.
- 받은 `.dmg` 파일을 두 번 클릭해 열어요.

![Aside 공식 사이트 첫 화면 - Download for macOS 버튼](/assets/blog/guide/aside-browser-setup/AS-01.png)

## 2단계. 응용 프로그램에 넣기

- 창이 열리면 Aside 아이콘을 **Applications** 폴더로 끌어다 놓아요.

![dmg 설치 창 - Aside 아이콘과 Applications 폴더](/assets/blog/guide/aside-browser-setup/AS-02.png)

*이 그림은 재현 이미지예요. 아이콘은 실제 것이지만 창 배경은 실제 설치 창과 다를 수 있어요.*

## 3단계. 로그인 또는 계정 만들기

- Aside를 처음 열면 **Sign in to Aside** 화면이 나와요.
- 이메일을 넣고 **Continue**를 누르거나, **Sign in with Google**로 바로 들어가요.
- 계정이 없으면 아래 **I don't have an account**를 눌러요. **Create your account** 화면으로 넘어갑니다.
- 이 계정은 Aside 자체 계정이에요. 뒤에서 연결할 ChatGPT나 Claude 계정과는 별개입니다.

![Aside 로그인 화면 - Continue 버튼과 계정 만들기 링크](/assets/blog/guide/aside-browser-setup/AS-03.png)

로그인하면 온보딩이 이어져요. 순서는 이래요.

1. **Welcome to Aside** 환영 화면. **Let's start**를 눌러요.
2. **Choose your AI subscription** 화면. 여기서 바로 ChatGPT나 Claude를 연결해도 되고, 건너뛰고 3부에서 해도 돼요.
3. **Import browser setup** 화면. 다음 2부예요.
4. 비밀번호 가져오기와 계정 보호 설정. 화면을 따라가면 돼요.

# 2부. 브라우저 데이터 가져오기

이 단계를 건너뛰면 뒤에서 다 막혀요. 꼭 해 주세요.

- 온보딩 중 **Import browser setup** 화면이 나와요.
- Aside가 쓰던 브라우저를 알아서 찾아 **Detected browser** 아래에 보여 줘요. 고를 필요 없이 이미 선택되어 있어요.
- 프로필이 여러 개면 여기서 바꿀 수 있어요.
- **Import**를 누르면 돼요. 옆의 Skip은 건너뛰기라 누르지 마세요.
- macOS가 시스템 접근 권한을 물으면 허용해요.
- **방문 기록, 쿠키, 북마크**가 함께 옮겨져요.

![브라우저 데이터 가져오기 화면 - 감지된 브라우저와 Import 버튼](/assets/blog/guide/aside-browser-setup/AS-04.png)

**Safari를 쓰신다면** 조금 달라요. Safari에서 `파일 > 내보내기`로 ZIP 파일을 만든 뒤 그 파일을 올려야 해요. ZIP이 아닌 파일은 받지 않습니다.

**왜 쿠키가 중요한가요?**

- 쿠키는 "이 사람 로그인했음"이라는 출입증이에요.
- 이게 없으면 Aside가 쿠팡에 들어가지 못하고 로그인 화면에서 멈춰요.
- 출입증을 넘겨주는 작업이니, 가져온 뒤 아래 "안전하게 쓰는 규칙"을 꼭 읽어 주세요.

가져오기가 끝나면 비밀번호 관리자 설정으로 이어져요. 여기서 저장해 둔 비밀번호는 AI에게 직접 노출되지 않고, 자동 입력할 때만 정책을 확인한 뒤 쓰입니다.

# 3부. AI 모델 연결하기

Aside는 두뇌를 직접 만들지 않아요. 세 가지 중 하나를 고릅니다. 설정 위치는 **Settings > Models**예요. 왼쪽에 **Providers**와 **Task models**가 보이는데, 둘 다 같은 페이지 안의 위치 이동 버튼이에요. 별도 페이지가 아닙니다.

## 방법 1. Aside 기본 모델

- 설치하면 바로 쓸 수 있어요. 무료 플랜에는 무료 모델 세트가 들어 있어요.
- Pro나 Max 플랜을 쓰면 더 많은 모델과 우선 모델을 쓸 수 있어요.
- 처음 써 보는 분은 이걸로 시작해도 충분해요.

## 방법 2. 내 구독 연결 (추천)

- Providers 목록 오른쪽의 **Connect** 버튼을 눌러요. 목록에 처음부터 ChatGPT가 보이지는 않아요.
- 펼쳐진 메뉴의 **Subscription** 그룹에 ChatGPT, Claude, GitHub Copilot 등이 있어요. 쓰는 걸 고르세요.
- 해당 서비스 로그인 창이 뜨고, 평소 계정으로 로그인하면 끝이에요.
- 연결되면 목록에 한 줄 추가돼요. 아래 화면에서는 Claude가 이미 연결된 상태예요.
- 이미 내는 구독료로 쓰는 거라 추가 비용이 없어요. 연결한 구독의 사용량 표시도 볼 수 있어요.

![Settings > Models의 Providers 섹션 - 연결된 Claude 행과 Connect 메뉴의 ChatGPT](/assets/blog/guide/aside-browser-setup/AS-05.png)

## 방법 3. API 키 넣기

- 같은 Connect 메뉴의 **API** 그룹에 Anthropic, OpenAI, Google, OpenRouter 등 열 곳 넘게 있어요.
- 쓴 만큼 내는 방식이라 자주 돌릴 분에게 맞아요.
- 넣은 뒤에는 공급자 메뉴에서 수정하거나 끊을 수 있어요.
- 맨 아래 **Local** 그룹에는 LM Studio와 Ollama가 있어요. 내 컴퓨터에서 모델을 돌리는 분만 해당돼요.

**어떤 모델을 쓸지 정하는 곳**은 같은 페이지의 **Task models** 섹션이에요. Default, Fast, Standard, Deep, Visual, Image generation 여섯 칸이 있는데 처음엔 **Default model**만 신경 쓰면 돼요. 목록에서 가장 최신 모델을 고르면 돼요. 2026년 9월 초에 나온 **GPT-6 Astra**는 브라우저 조작에 특히 강한데, 이 글을 쓴 9월 13일 기준 Aside 목록에는 아직 없어요. 들어오면 여기서 고르면 됩니다.

# 4부. 첫 작업, 쿠팡 주문을 결제 직전까지

## 권한, 딱 하나만 확인하면 돼요

작업은 오른쪽 **사이드 패널**의 입력창에 문장을 적으면 시작돼요. 입력창 아래 줄에 프로젝트, 모델, 추론 강도와 함께 **권한 모드** 드롭다운이 항상 떠 있어요. 작업할 때마다 고르는 게 아니라 언제든 바꾸는 스위치예요.

| 모드 | 뜻 |
|---|---|
| Read only | 보기만 하고 파일을 바꾸지 않아요 |
| Guard | 허용한 폴더 안에서만 작업하고, 다른 폴더는 물어봐요 |
| Full access | 컴퓨터 어디든 읽고 써요 |

**쿠팡 주문은 파일을 안 건드리니 Guard면 충분해요.** 설치 직후 Full access로 되어 있다면 Guard로 내려 두세요.

권한은 사실 네 층이에요. 지금은 위 하나만 알면 되고, 나머지 셋은 파일을 다루는 작업을 할 때 **Settings > Agents**에서 만나게 돼요.

- **File permissions**: 볼 수 있는 폴더(Can view)와 고칠 수 있는 폴더(Can edit) 목록. 기본은 프로젝트 폴더 하나예요.
- **Sandbox**: 명령 실행을 허용된 폴더 안으로 가두는 토글이에요.
- **Tool permissions**: 도구별로 허용, 물어보기, 거부를 정해요.

## 프롬프트 붙여넣기

단순히 "제일 싼 거 골라 줘"보다 조금 어려운 일을 시켜 볼게요. 사람이 직접 하면 한참 걸리는 일이에요.

쿠팡은 단백질 보충제에 "10g당 얼마"라는 단가를 보여 줘요. 그런데 그건 가루 10g 기준이지 단백질 10g 기준이 아니에요. 진짜로 비교하려면 상품마다 영양 정보를 찾아 단백질 1g당 가격을 직접 계산해야 하죠. 그걸 시켜 봅니다.

```
쿠팡에서 "단백질 보충제"를 검색해 줘.

조건:
- 리뷰가 1,000개 이상인 상품만 봐.
- 쿠팡이 보여 주는 "10g당 얼마" 단가는 믿지 말고,
  상품 상세의 영양 정보에서 1회 제공량당 단백질 g을 찾아
  "단백질 1g당 가격"을 직접 계산해.
- 영양 정보가 이미지 안에만 있으면 이미지를 읽어서 확인해.
- 단백질 1g당 가격이 가장 낮은 상품 하나를 골라 장바구니에 담아.
- 결제 화면까지만 가. 결제 버튼은 절대 누르지 말고 멈춰서 알려 줘.

보고:
- 비교한 상품을 이름 / 가격 / 쿠팡 표시 단가 / 단백질 1g당 가격 표로.
- 로그인이 풀려 있거나 인증 화면이 나오면 멈추고 알려 줘.
```

![사이드 패널 입력창에 프롬프트를 넣은 상태 - 아래 줄의 권한 모드 드롭다운](/assets/blog/guide/aside-browser-setup/AS-06.png)

입력창 아래 줄은 왼쪽부터 프로젝트, 권한 모드, 오른쪽에 모델과 추론 강도예요. 위 화면은 제 설정이라 **Full access**로 되어 있는데, 따라 하실 때는 이걸 눌러 **Guard**로 바꿔 두세요.

## 실행 중에 보이는 것

이게 Aside가 다른 AI와 다른 지점이에요. 한 화면에 세 가지가 동시에 보여요.

![작업 진행 중 화면 - 단계 보고, 에이전트가 조작 중인 쿠팡 탭, 제어 중 오버레이](/assets/blog/guide/aside-browser-setup/AS-07.png)

- ① 오른쪽 패널에서 지금 무엇을 하는지 한 줄씩 보고해요. 위 화면에서는 "영양 정보가 텍스트로는 일관되게 안 나와서 상세 이미지를 직접 읽겠다"고 말하고 있어요.
- ② 가운데 탭에서 실제로 쿠팡을 조작해요.
- ③ 탭 아래 **Aside is controlling the tab** 표시가 떠요. 옆의 **Take over**를 누르면 언제든 제가 넘겨받을 수 있어요.

이 화면은 제 맥에서 직접 찍은 거예요. 실제 앱은 이렇게 다크 모드가 기본입니다.

## 제가 돌렸을 때 나온 결과

2026년 9월 13일에 돌린 결과예요. 가격은 그날 기준입니다.

| 제품 | 가격 | 쿠팡 표시 단가 | 단백질 1g당 |
|---|---|---|---|
| 뉴욕웨이 라이트 2kg | 36,700원 | 10g당 184원 | **26.2원** |
| 퍼스널벌크 게이너 3.2kg | 25,400원 | 10g당 79원 (표시 최저) | 37.8원 |
| 더단백 드링크 250ml×18 | 23,710원 | 100ml당 527원 | 65.9원 |
| 하이뮨 액티브 250ml×18 | 25,480원 | 표시 없음 | 70.8원 |
| 신타-6 2.27kg | 89,960원 | 10g당 396원 | 84.6원 |

세 가지가 눈에 띄었어요.

- **순위가 뒤집혔어요.** 쿠팡 표시 단가로는 게이너가 가장 싼데, 단백질 1g당으로 보면 뉴욕웨이보다 44% 비쌉니다. 게이너는 단백질 비율이 21%밖에 안 돼서요.
- **음료는 비교 자체가 안 됐어요.** 100ml당 가격으로 표시돼서 가루와 나란히 놓을 수가 없었어요. Aside가 병당 단백질 양을 찾아 다시 계산했습니다.
- **숫자가 이미지 안에만 있는 상품이 있었어요.** 더단백의 "단백질 20g"은 본문 텍스트 어디에도 없고 상세 이미지에만 적혀 있었어요. 실제로 그 상품 문의란에는 "단백질 몇 g인지 알려 달라"는 질문이 남아 있습니다. Aside는 이미지를 읽어서 채웠어요.

최종 선택은 뉴욕웨이 라이트 2kg이었고, 장바구니에 담긴 뒤 결제 화면에서 멈췄어요.

## 결제 직전에 멈춥니다

- 장바구니에 담고 주문/결제 화면에 들어가면 Aside가 멈추고 저를 불러요.
- 상품과 금액을 확인하고, 마음에 들면 제가 직접 **결제하기**를 눌러요.
- 마음에 안 들면 "다른 걸로 골라 줘"라고 말하면 돼요.

![쿠팡 주문/결제 화면 - 결제하기 버튼 직전에서 정지](/assets/blog/guide/aside-browser-setup/AS-08.png)

멈췄다는 말은 오른쪽 사이드 패널에 떠요. 쿠팡 화면 자체에는 아무 표시가 없고, 결제하기 버튼이 눌리지 않은 채 그대로 있는 게 전부예요.

Aside는 결제, 게시물 작성, 메시지 발송처럼 되돌리기 어려운 행동에 **사람 승인 관문**을 두도록 만들어졌어요. 돈이 나가는 일을 AI가 혼자 결정하지 않는다는 뜻이에요.

## 이 예시가 끝나면 할 수 있는 것

같은 방식으로 문장만 바꾸면 돼요.

# 안전하게 쓰는 규칙

로그인 상태를 넘겨주는 도구예요. 편한 만큼 조심할 부분이 있어요.

- **처음부터 큰일을 맡기지 마세요.** 링크 확인 같은 읽기 작업으로 감을 잡으세요.
- **화면을 보면서 돌리세요.** 첫 몇 번은 옆에 앉아 지켜봐 주세요.
- **은행, 증권, 관공서 탭은 미리 닫아 두세요.** 같은 브라우저 안에 있을 이유가 없어요.
- **결제 버튼은 프롬프트에서 항상 금지하세요.** 위 예시처럼 "결제는 내가 한다"를 매번 적어요.
- **입력창 아래 권한 모드는 Guard로 두세요.** Full access는 파일을 다루는 작업을 확실히 이해한 뒤에만 켜세요.
- **비밀번호는 Aside 비밀번호 관리자에 맡기세요.** 저장된 비밀번호는 AI에게 직접 보이지 않고, 자동 입력 때만 정책 확인을 거쳐 쓰여요.

# 개발자라면 Claude Code에 붙일 수 있어요

터미널에서 쓰시는 분만 읽으세요.

- CLI는 **Settings > Developers**의 **Aside CLI** 섹션에서 **Install**을 누르거나, 터미널에서 공식 설치 스크립트를 실행해요.

```
curl -fsSL https://releases.aside.com/install.sh | bash
```

- 같은 화면 **Skill & MCP** 섹션에서 **Enable Aside MCP server** 토글을 켜요. 옆의 **How to set up MCP server?** 링크에 도구별 안내가 있어요.
- 터미널에서는 `aside mcp`로 실행하고, `mcp.json`을 쓰는 도구라면 아래처럼 항목을 추가해요.

```json
{
  "mcpServers": {
    "aside": {
      "command": "aside",
      "args": ["mcp"]
    }
  }
}
```

![Aside 설정 Developers 화면 - CLI Install 버튼과 MCP 서버 설정](/assets/blog/guide/aside-browser-setup/AS-09.png)

Remote Control 항목은 Pro 플랜 전용이라 무료에서는 꺼져 있어요.

이렇게 붙이면 Claude Code가 필요할 때 Aside를 브라우저로 불러 써요. 배포 후 화면 확인이나 로그인 페이지 테스트에 편해요.

# GPT-6 Astra랑 무슨 관계인가요?

요즘 많이 받는 질문이라 정리해 둘게요.

- **Astra는 두뇌예요.** 2026년 9월 3일에 나온 OpenAI 모델이고, 브라우저 조작과 긴 작업에 강해요.
- **Aside는 몸이에요.** 내 로그인 쿠키를 들고 실제로 클릭하는 브라우저예요.
- 둘은 경쟁이 아니라 **조합**이에요. 다만 이 글을 쓴 시점에는 Aside 모델 목록에 Astra가 아직 없어요. 들어오면 Task models에서 고르면 됩니다. Astra가 무엇인지는 [별도 글](/guide/gpt-6-astra)에 정리했어요.

OpenAI도 자체 브라우저 Atlas를 만들었지만 **2026년 8월 9일에 종료**했어요. 출시 292일 만에 접고, 브라우저 자동화를 ChatGPT와 Codex 안으로 옮겼습니다. 지금 "내 로그인 상태를 쓰는 독립 브라우저" 자리는 Aside 같은 제품이 채우고 있어요.
