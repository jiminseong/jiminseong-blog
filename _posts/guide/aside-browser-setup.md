"AI가 대신 클릭해 준다"는 말을 들으면 뭔가 복잡한 설정이 떠오르죠. 이 글은 그 반대예요.

- 설치하고 계정 만들고 브라우저 데이터 가져오면 준비 끝이에요.
- 첫 작업으로 **쿠팡에서 물건 하나를 골라 결제 직전까지** 맡겨 봅니다.
- 준비 포함 20분, 두 번째부터는 문장 하나 붙여넣기예요.

이 글의 주소는 `jiminseong.com/guide/aside-browser-setup` 입니다. 설정 순서는 Aside 공식 도움말을 기준으로 썼어요.

# Aside가 뭔가요?

한 줄로 말하면 **AI가 대신 쓰는 브라우저**예요.

지금까지의 AI는 이랬어요.

- 내가 화면을 보고, 내가 클릭하고, 막히면 AI에게 물어봤어요.
- AI는 조언만 해 주고 클릭은 못 했어요.

Aside는 이 관계가 뒤집혀요.

- 내가 할 일을 문장으로 말해요.
- AI가 브라우저를 직접 열고 클릭해요.
- 나는 결과만 확인해요.

**핵심은 "로그인 상태"예요.** 보통의 AI는 내 쿠팡 계정에 들어갈 수 없어요. Aside는 내가 평소 쓰는 브라우저의 쿠키를 그대로 물려받아서, 이미 로그인된 상태로 일을 시작해요. 그래서 공개 API가 없는 국내 사이트도 자동화가 됩니다.

비유하면 이래요.

- 기존 AI는 전화로 길 알려 주는 친구예요.
- Aside는 조수석에 앉아 직접 운전대를 잡는 친구예요.

Y Combinator 투자를 받은 한국인 창업팀이 만들었고, 브라우저 에이전트 벤치마크 1위를 주장하고 있어요. 다만 이 순위는 자체 측정 기준이라는 점은 알아 두세요.

# 시작 전에 확인할 것

| 항목 | 필요한 것 |
|---|---|
| 운영체제 | **macOS 15.0 이상**. 윈도우는 아직 개발 중이에요. |
| Aside 계정 | 필수예요. 첫 실행 때 만들면 됩니다. |
| AI 구독 | 없어도 돼요. 무료 플랜의 기본 모델로 시작할 수 있고, ChatGPT나 Claude 구독이 있으면 연결하면 돼요. |
| 쿠팡 계정 | 평소 쓰는 브라우저에 로그인되어 있으면 좋아요. |
| 결제 수단 | 결제는 **제가 직접** 합니다. Aside는 결제 직전에 멈춰요. |

윈도우를 쓰신다면 아직 Aside는 못 써요. 같은 일을 GPT로 하는 방법은 별도 글로 준비하고 있습니다.

# 1부. 설치하고 계정 만들기

## 1단계. 내려받기

- `aside.com/download`에 접속해 내려받아요.
- 받은 `.dmg` 파일을 두 번 클릭해 열어요.

[Aside 캡처 AS-01: aside.com 다운로드 페이지. 다운로드 버튼이 강조된 영역]

## 2단계. 응용 프로그램에 넣기

- 창이 열리면 Aside 아이콘을 **Applications** 폴더로 끌어다 놓아요.

[Aside 캡처 AS-02: dmg 설치 창. Aside 아이콘을 Applications 폴더로 끄는 화면]

## 3단계. 로그인 또는 계정 만들기

- Aside를 처음 열면 로그인 화면이 나와요.
- 계정이 없으면 여기서 만들어요. 이 계정은 Aside 자체 계정이고, 뒤에서 연결할 ChatGPT나 Claude 계정과는 별개예요.

[Aside 캡처 AS-03: 첫 실행 시 로그인·계정 만들기 화면]

# 2부. 브라우저 데이터 가져오기

이 단계를 건너뛰면 뒤에서 다 막혀요. 꼭 해 주세요.

- 계정을 만들면 온보딩 중에 기존 브라우저 데이터를 가져올지 물어봐요.
- 쓰던 브라우저를 고르고, 프로필이 여러 개면 가져올 프로필을 선택해요.
- macOS가 시스템 접근 권한을 물으면 허용해요.
- **방문 기록, 쿠키, 북마크**가 함께 옮겨져요.

[Aside 캡처 AS-04: 브라우저 데이터 가져오기 화면. 브라우저와 프로필 선택 영역이 강조된 화면]

**Safari를 쓰신다면** 조금 달라요. Safari에서 `파일 > 내보내기`로 ZIP 파일을 만든 뒤 그 파일을 올려야 해요. ZIP이 아닌 파일은 받지 않습니다.

**왜 쿠키가 중요한가요?**

- 쿠키는 "이 사람 로그인했음"이라는 출입증이에요.
- 이게 없으면 Aside가 쿠팡에 들어가지 못하고 로그인 화면에서 멈춰요.
- 출입증을 넘겨주는 작업이니, 가져온 뒤 아래 "안전하게 쓰는 규칙"을 꼭 읽어 주세요.

가져오기가 끝나면 비밀번호 관리자 설정으로 이어져요. 여기서 저장해 둔 비밀번호는 AI에게 직접 노출되지 않고, 자동 입력할 때만 정책을 확인한 뒤 쓰입니다.

# 3부. AI 모델 연결하기

Aside는 두뇌를 직접 만들지 않아요. 세 가지 중 하나를 고릅니다. 설정 위치는 **Settings > Models > Providers**예요.

## 방법 1. Aside 기본 모델

- 설치하면 바로 쓸 수 있어요. 무료 플랜에는 무료 모델 세트가 들어 있어요.
- Pro나 Max 플랜을 쓰면 더 많은 모델과 우선 모델을 쓸 수 있어요.
- 처음 써 보는 분은 이걸로 시작해도 충분해요.

## 방법 2. 내 구독 연결 (추천)

- ChatGPT Plus/Pro, Claude Pro/Max, GitHub Copilot 구독을 연결할 수 있어요.
- 누르면 해당 서비스 로그인 창이 뜨고, 평소 계정으로 로그인하면 끝이에요.
- 이미 내는 구독료로 쓰는 거라 추가 비용이 없어요.
- 연결한 구독의 사용량 표시도 볼 수 있어요.

[Aside 캡처 AS-05: Settings > Models > Providers 화면. 구독 연결 항목이 강조된 영역]

## 방법 3. API 키 넣기

- Anthropic, OpenAI, OpenRouter, Google, xAI, Vercel AI Gateway, Cloudflare AI Gateway를 넣을 수 있어요.
- 쓴 만큼 내는 방식이라 자주 돌릴 분에게 맞아요.
- 넣은 뒤에는 공급자 메뉴에서 수정하거나 끊을 수 있어요.

**어떤 모델을 쓸지 정하는 곳**은 따로 있어요. **Settings > Models > Task models**에서 기본 모델을 고릅니다. 목록에서 가장 최신 모델을 고르면 돼요. 2026년 9월 초에 나온 **GPT-6 Astra**는 브라우저 조작과 긴 작업에 특히 강하니, 목록에 보이면 그걸 고르세요.

# 4부. 첫 작업, 쿠팡 주문을 결제 직전까지

## 작업 시작 화면 이해하기

작업은 **작업 페이지**나 **사이드 패널**에서 시작해요. 시작할 때 세 가지를 정합니다.

1. **무엇을 원하는지** 문장으로 적어요. 사이트, 계정, 원하는 결과를 이름으로 불러 주면 좋아요.
2. **권한 모드**를 골라요. 기본값은 **Guard**예요.
3. **작업 폴더**를 골라요. 파일을 다루는 작업일 때만 필요해요.

권한 모드는 세 가지예요.

| 모드 | 뜻 |
|---|---|
| Read only | 보기만 하고 파일을 바꾸지 않아요 |
| Guard (기본) | 허용한 폴더 안에서만 작업하고, 다른 폴더는 물어봐요 |
| Full access | 컴퓨터 어디든 읽고 써요 |

**쿠팡 주문은 파일이 필요 없어요.** 작업 폴더는 고르지 말고, 권한 모드는 Guard 그대로 두세요. 허용 폴더 목록은 **Settings > Agents > File permissions**에서 나중에 관리할 수 있어요.

## 프롬프트 붙여넣기

아래 문장에서 대괄호 한 곳만 바꿔서 붙여넣으세요.

```
쿠팡에서 [상품 이름]을 검색해 줘.

조건:
- 리뷰가 1,000개 이상인 상품 중에서 평점이 가장 높은 것 하나를 골라.
- 옵션은 기본값 그대로 두고 장바구니에 담아.
- 결제 화면까지만 가. 결제는 내가 직접 할 테니
  결제 버튼은 절대 누르지 말고 멈춰서 알려 줘.

보고:
- 고른 상품의 이름, 가격, 평점, 리뷰 수를 한 줄로.
- 로그인이 풀려 있거나 인증 화면이 나오면 멈추고 알려 줘.
```

[Aside 캡처 AS-06: 작업 시작 화면. 위 프롬프트가 입력되어 있고 권한 모드가 Guard, 작업 폴더는 비어 있는 상태]

실행하면 이렇게 흘러가요.

- Aside가 쿠팡을 열고 검색하고 상품을 비교하는 모습이 실시간으로 보여요.
- 지금 몇 번째 단계인지 글로 알려 줘요.
- 이상하면 언제든 멈출 수 있어요.

[Aside 캡처 AS-07: 작업 진행 화면. 단계 보고와 쿠팡 검색 결과가 함께 보이는 전체 창]

## 결제 직전에 멈춥니다

- 장바구니에 담고 결제 화면에 들어가면 Aside가 멈추고 저를 불러요.
- 상품과 금액을 확인하고, 마음에 들면 제가 직접 결제해요.
- 마음에 안 들면 "다른 걸로 골라 줘"라고 말하면 돼요.

[Aside 캡처 AS-08: 쿠팡 결제 화면에서 Aside가 사용자 확인이 필요하다고 멈춘 상태]

Aside는 결제, 게시물 작성, 메시지 발송처럼 되돌리기 어려운 행동에 **사람 승인 관문**을 두도록 만들어졌어요. 돈이 나가는 일을 AI가 혼자 결정하지 않는다는 뜻이에요.

## 이 예시가 끝나면 할 수 있는 것

같은 방식으로 문장만 바꾸면 돼요.

- "지난달 카드 명세서에서 구독 결제만 골라 표로 정리해 줘"

# 안전하게 쓰는 규칙

로그인 상태를 넘겨주는 도구예요. 편한 만큼 조심할 부분이 있어요.

- **처음부터 큰일을 맡기지 마세요.** 링크 확인 같은 읽기 작업으로 감을 잡으세요.
- **화면을 보면서 돌리세요.** 첫 몇 번은 옆에 앉아 지켜봐 주세요.
- **은행, 증권, 관공서 탭은 미리 닫아 두세요.** 같은 브라우저 안에 있을 이유가 없어요.
- **결제 버튼은 프롬프트에서 항상 금지하세요.** 위 예시처럼 "결제는 내가 한다"를 매번 적어요.
- **권한 모드는 Guard로 두세요.** Full access는 파일을 다루는 작업을 확실히 이해한 뒤에만 켜세요.
- **비밀번호는 Aside 비밀번호 관리자에 맡기세요.** 저장된 비밀번호는 AI에게 직접 보이지 않고, 자동 입력 때만 정책 확인을 거쳐 쓰여요.

# 개발자라면 Claude Code에 붙일 수 있어요

터미널에서 쓰시는 분만 읽으세요.

- CLI는 **Settings > Developers**의 설치 버튼으로 깔거나, 터미널에서 공식 설치 스크립트를 실행해요.

```
curl -fsSL https://releases.aside.com/install.sh | bash
```

- MCP 서버로 쓰려면 `aside mcp`를 실행해요.
- `mcp.json`을 쓰는 도구라면 아래처럼 항목을 추가해요.

```json
{
  "mcpServers": {
    "aside": {
      "command": "aside",
      "args": ["mcp"]
    }
  }
}
```

[Aside 캡처 AS-09: Settings > Developers 화면. CLI 설치와 MCP 안내가 보이는 영역]

이렇게 붙이면 Claude Code가 필요할 때 Aside를 브라우저로 불러 써요. 배포 후 화면 확인이나 로그인 페이지 테스트에 편해요.

# GPT-6 Astra랑 무슨 관계인가요?

요즘 많이 받는 질문이라 정리해 둘게요.

- **Astra는 두뇌예요.** 2026년 9월 3일에 나온 OpenAI 모델이고, 브라우저 조작과 긴 작업에 강해요.
- **Aside는 몸이에요.** 내 로그인 쿠키를 들고 실제로 클릭하는 브라우저예요.
- 둘은 경쟁이 아니라 **조합**이에요. Task models 설정에서 Astra를 고르면 같이 쓰는 거예요.

OpenAI도 자체 브라우저 Atlas를 만들었지만 **2026년 8월 9일에 종료**했어요. 출시 292일 만에 접고, 브라우저 자동화를 ChatGPT와 Codex 안으로 옮겼습니다. 지금 "내 로그인 상태를 쓰는 독립 브라우저" 자리는 Aside 같은 제품이 채우고 있어요.

# 마치며

정리하면 이래요.

1. Aside를 설치하고 계정을 만들었어요.
2. 브라우저 데이터를 가져왔어요.
3. AI 모델을 연결했어요.
4. 쿠팡 주문을 결제 직전까지 맡겨 봤어요.

한 번 설치해 두면 다음부터는 문장만 바꿔 쓰면 돼요.

- 아직 맥 전용이에요. 윈도우 버전은 개발 중입니다.
- 같은 일을 GPT로 하는 방법은 별도 글로 정리할게요.
