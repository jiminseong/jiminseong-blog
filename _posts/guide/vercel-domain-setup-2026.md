Vercel로 사이트를 처음 만들면 주소가 `내프로젝트.vercel.app`처럼 나와요. 잘 작동하지만, 명함에 적기엔 조금 아쉽죠.

이 글에서는 **가비아에서 도메인을 사고, Vercel에 붙이는 과정**을 화면 한 장 한 장 따라 해 봅니다.

- 코딩 지식이 전혀 없어도 괜찮아요.
- 모든 화면을 캡처해 두었으니 그림만 보고 따라오셔도 돼요.
- 15분이면 끝나고, 반영까지 길어야 하루예요.

이 글의 주소는 `jiminseong.com/guide/vercel-domain-setup-2026` 입니다. 이 주소의 `jiminseong.com` 역시 지금 설명하는 방법 그대로 연결했어요. 화면 캡처도 전부 제 실제 계정에서 찍은 것입니다.

# 오늘 쓰는 사이트는 딱 두 곳이에요

헷갈리지 않게 각자 역할을 먼저 정해 둘게요.

| 사이트 | 역할 | 여기서 하는 일 |
|---|---|---|
| **가비아** | 도메인을 사고 주소록을 관리하는 곳 | 도메인 구매, 그리고 "이 도메인은 이 서버로 가세요"라고 적어 두기 |
| **Vercel** | 도메인을 붙이는 곳 | 도메인을 등록하고, 가비아에 적을 값을 알려 주기 |

순서는 이렇게 갑니다.

1. **가비아**에서 도메인을 산다.
2. **Vercel**에 그 도메인을 등록하고, 값 한 줄을 받는다.
3. **가비아**에 그 값을 적는다.
4. **Vercel**에서 연결됐는지 확인한다.

가비아와 Vercel을 두 번씩 오가는 게 전부예요.

# 시작 전에: 딱 3개 용어만 알고 가요

스마트폰 연락처에 비유하면 금방 이해돼요.

**도메인 (Domain)**

- `jiminseong.com` 같은 사이트 주소예요.
- 연락처에 저장된 **친구 이름**이라고 생각하면 돼요.

**DNS**

- 이름을 실제 전화번호로 바꿔 주는 **연락처 앱** 자체예요.
- 사람이 도메인만 입력해도 서버를 찾아가게 해 줍니다.

**A 레코드 (A Record)**

- 연락처에 적는 **전화번호 한 줄**이에요.
- "이 이름으로 전화가 오면 이 번호로 연결해 주세요"라고 적어 두는 것과 같아요.
- 3번 순서에서 가비아에 적을 값이 바로 이거예요.

우리가 할 일은 연락처 앱을 통째로 바꾸는 게 아니라, **번호 한 줄을 적는 것**입니다. 그래서 기존에 쓰던 이메일이나 다른 설정은 그대로 살아 있어요.

# 1부. 가비아에서 도메인 사기

## 1단계. 로그인

- 가비아 홈페이지에 접속해 로그인합니다.
- 구글, 네이버, 카카오 간편 로그인을 쓸 수 있어요. 왼쪽부터 구글, 네이버, 카카오 순서로 놓여 있습니다.

![가비아 로그인 페이지 - 간편 로그인 버튼](/assets/blog/guide/vercel-domain-setup-2026/01.png)

## 2단계. 도메인 검색

- 메인 화면 가운데 검색창에 원하는 이름을 입력하고 **검색**을 눌러요.

![가비아 메인 도메인 검색창 - 검색 입력칸과 검색 버튼](/assets/blog/guide/vercel-domain-setup-2026/02.png)

## 3단계. 등록 가능한 도메인 고르기

- 결과에 `.com`, `.kr`, `.co.kr` 등 여러 종류가 나와요.
- 살 수 있는 것만 오른쪽에 **선택** 버튼이 있어요.
- 원하는 도메인 행의 **선택**을 누릅니다.

![가비아 도메인 검색 결과 - 등록 가능한 .com 행의 선택 버튼](/assets/blog/guide/vercel-domain-setup-2026/03.png)

처음이라면 `.com`을 추천해요. 한국 대상 서비스면 `.kr`도 좋아요.

## 4단계. 장바구니에서 신청하기

- 선택한 도메인이 오른쪽 **도메인 장바구니** 패널에 담겨요.
- 별도의 장바구니 페이지로 넘어가지 않아요. 같은 화면 오른쪽에 그대로 붙어 있습니다.
- 패널 아래 **신청하기**를 눌러요.

![가비아 도메인 장바구니 패널 - 신청하기 버튼](/assets/blog/guide/vercel-domain-setup-2026/04.png)

## 5단계. 신청 정보 입력

- 화면 위에 `1 신청 정보 입력 → 2 서비스 비용 결제 → 3 정보 확인` 순서가 보여요.
- **등록 기간의 기본값은 3년입니다.** 처음이라면 **1년**으로 바꾸세요.
- 부가 서비스는 `안전잠금` 토글 하나뿐이고, 기본값이 꺼짐이에요. 그대로 두면 됩니다.

![가비아 신청 정보 입력 - 등록 기간 1년과 안전잠금 토글](/assets/blog/guide/vercel-domain-setup-2026/05.png)

## 6단계. 소유자 정보와 결제

이 단계는 개인정보가 많이 들어가서 캡처를 넣지 않았어요. 화면을 따라가시면 됩니다.

- **소유자명을 영문으로** 입력해야 해요. 회원정보를 불러와도 영문 이름은 자동으로 채워지지 않습니다.
- **소유자 이메일 인증**이 필요해요. 인증 메일이 오면 링크를 눌러 주세요.
- 전화번호, 우편번호, 한글 주소, 영문 주소가 모두 필수예요. 미리 준비해 두면 빨라요.
- 인증과 입력을 마치면 결제 수단을 고르고 결제합니다.
- 몇 분 안에 "도메인 등록 완료" 알림이 오면 이제 이 도메인은 여러분 거예요.

# 2부. Vercel에 도메인 등록하고 값 받기

이제 Vercel로 갑니다. 여기서 받은 값을 3부에서 가비아에 적을 거예요.

## 1단계. Domains 화면 열기

- Vercel에 로그인해 도메인을 붙일 **프로젝트**를 클릭해요.
- 왼쪽 메뉴에서 **Domains**를 바로 누릅니다.
- Settings 안에 있지 않아요. 왼쪽 목록의 독립 항목이고, Settings는 맨 아래 따로 있습니다.

![Vercel 프로젝트 화면 - 왼쪽 사이드바의 Domains 메뉴](/assets/blog/guide/vercel-domain-setup-2026/07.png)

## 2단계. 도메인 추가

- 오른쪽 위에 버튼이 두 개 있어요. **Add Existing**과 **Buy**입니다.
- 가비아에서 이미 샀으니 **Add Existing**을 누릅니다.
- `Add Domains` 팝업이 열리면 도메인을 입력해요.
- 입력 전에는 버튼이 `Add 0 Domains`로 비활성이고, 입력하면 `Add Domain`으로 바뀝니다.

![Vercel Add Domains 팝업 - 도메인 입력칸과 Add Domain 버튼](/assets/blog/guide/vercel-domain-setup-2026/08.png)

- 같은 팝업 안에 `Redirect apex domains to www (recommended)` 체크박스가 있어요.
- **기본값이 이미 체크되어 있습니다.** 그대로 두면 `mysite.com`으로 들어와도 `www.mysite.com`으로 자동 이동돼요.

![Vercel Add Domains 팝업 - www 리다이렉트 체크박스](/assets/blog/guide/vercel-domain-setup-2026/09.png)

## 3단계. 적어야 할 값 확인

- 도메인이 추가되면 목록에 주황색 경고와 함께 나타나요.
- 아직 가비아에 값을 적기 전이라 정상입니다.
- 도메인 옆 **View DNS configuration**을 눌러 펼쳐요.

![Vercel 도메인 카드 - DNS Change Recommended 배지와 View DNS configuration](/assets/blog/guide/vercel-domain-setup-2026/10.png)

- 펼치면 표가 하나 나와요. 이게 가비아에 적을 값입니다.

![Vercel DNS 설정 안내 표 - Name과 Value의 복사 아이콘](/assets/blog/guide/vercel-domain-setup-2026/11.png)

| 항목 | 값 | 뜻 |
|---|---|---|
| Type | `A` | 종류는 A 레코드예요 |
| Name | `@` | 도메인 자기 자신을 뜻해요 |
| Value | 화면에 보이는 IP 주소 | 연결할 서버 번호예요 |

**중요:** IP 주소는 **반드시 본인 화면에 뜬 값을 복사**하세요. 위 캡처의 숫자를 그대로 따라 적으면 안 됩니다. Vercel이 IP 대역을 넓히는 중이라 계정과 시점에 따라 값이 다를 수 있어요. 값 옆 복사 아이콘을 누르면 안전합니다.

# 3부. 가비아에 값 적기

## 1단계. 도메인 관리 화면으로 이동

- 가비아로 돌아와 오른쪽 위 **My가비아**를 클릭해요.

![가비아 상단 메뉴 - My가비아 버튼](/assets/blog/guide/vercel-domain-setup-2026/12.png)

- 왼쪽 **서비스 관리**를 누릅니다.
- 목록 위 드롭다운에서 **전체 서비스**를 **도메인**으로 바꿔요. 도메인만 있는 메뉴는 따로 없어요.
- 해당 도메인 행의 **관리** 버튼을 누릅니다.

![My가비아 서비스 목록 - 서비스 종류 드롭다운과 관리 버튼](/assets/blog/guide/vercel-domain-setup-2026/13.png)

## 2단계. DNS 관리 열기

**창이 두 번 바뀝니다.** 이걸 모르면 창을 잃어버리기 쉬우니 미리 알고 가세요.

1. **관리**를 누르면 새 창 `domains.gabia.com`이 열려요.
2. 그 창 왼쪽 메뉴에서 **DNS 관리**를 누르면 **또 다른 새 창** `dns.gabia.com`이 열려요.

즉 왼쪽 메뉴의 DNS 관리는 목적지가 아니라 통로예요. 진짜 작업은 세 번째 창에서 합니다.

![가비아 도메인 관리 창 - 왼쪽 사이드바의 DNS 관리 메뉴](/assets/blog/guide/vercel-domain-setup-2026/14.png)

**지름길도 있어요.** 다음부터는 이렇게 하시면 창을 한 번만 열어요.

- My가비아 상단의 **DNS관리툴** 버튼을 누르거나
- 주소창에 `dns.gabia.com`을 직접 입력하세요.

**헷갈리기 쉬운 이름 세 개**가 있어요. 위 캡처 가운데 `네임서버/DNS호스트/DNSSEC` 탭이 보이죠. 오늘은 그 탭을 누르지 않습니다.

- **네임서버**는 주소록 앱 자체를 바꾸는 기능이에요. 건드리면 메일이 끊길 수 있어요.
- **DNS 호스트**는 예전 방식이에요. 비어 있어도 정상입니다.
- 우리가 쓸 건 그 탭이 아니라 왼쪽 메뉴의 **DNS 관리**예요.

## 3단계. 레코드 목록 열기

- `dns.gabia.com`에서 내 도메인이 보이는지 확인해요.
- **DNS 설정** 옆 **레코드 수정** 버튼을 누릅니다.

![가비아 DNS 관리 - 도메인 이름과 레코드 수정 버튼](/assets/blog/guide/vercel-domain-setup-2026/15.png)

**이미 다른 줄이 있어도 지우지 마세요.** 위 캡처에는 세 줄이 있어요. 메일이나 사이트 인증에 쓰이는 값이라 지우면 그 기능이 멈춥니다. 우리는 A 레코드 한 줄만 더하거나 고칠 거예요.

## 4단계. A 레코드 넣기

- 레이어 왼쪽 아래 **+ 레코드 추가**를 누르면 빈 줄이 하나 생겨요.
- 이미 A 레코드가 있다면 그 줄의 **값/위치**만 새 IP로 바꾸면 됩니다.

칸 이름이 조금 낯설어요. 이렇게 채우면 됩니다.

| 칸 | 넣을 값 | 참고 |
|---|---|---|
| 타입 | `A` | 드롭다운에서 고릅니다 |
| 호스트 | `@` | 칸 아래 `.내도메인.com`이 회색으로 붙어 나와요 |
| 값/위치 | Vercel에서 복사한 IP 주소 | 칸 안내문이 "IP 주소"예요 |
| TTL | 기본값 그대로 (`600`) | 직접 입력이 아니라 드롭다운입니다 |
| 우선순위 | 비워 둡니다 | A 레코드에는 필요 없어요 |

![가비아 DNS 레코드 수정 - 새 줄에 타입 A, 호스트 @, IP를 입력한 상태와 저장 버튼](/assets/blog/guide/vercel-domain-setup-2026/16.png)

호스트에 `@`를 넣으면 칸 바로 아래 회색으로 `.내도메인.com`이 붙어요. `@`가 도메인 자기 자신을 뜻한다는 걸 눈으로 확인할 수 있는 지점이에요. 위 캡처에서 새로 만든 줄은 맨 아래에 있고, 원래 있던 세 줄은 위에 그대로 남아 있습니다.

**여기서 가장 흔한 사고가 납니다. 버튼을 두 번 눌러야 해요.**

1. 줄 오른쪽의 **확인**을 눌러 그 줄을 확정합니다.
2. 레이어 아래쪽의 **저장**을 눌러야 서버에 실제로 반영됩니다.

확인만 누르고 창을 닫으면 아무것도 저장되지 않아요. 저장까지 누르셨는지 꼭 확인하세요.

적기 전에 한 번만 점검해요.

- 앞뒤에 공백이 없는지
- 끝에 점(`.`)이 붙지 않았는지
- 숫자를 한 자리도 빠뜨리지 않았는지

제대로 저장됐는지 보려면 목록 위 **최근 업데이트** 시각을 보세요. 오늘 날짜로 바뀌어 있으면 반영된 거예요.

# 4부. Vercel에서 연결 확인하기

- Vercel의 Domains 화면으로 돌아가 해당 도메인 행의 **Refresh**를 눌러요.
- 파란 체크와 함께 **Valid Configuration**으로 바뀌면 성공이에요.

![Vercel Domains 화면 - Refresh 버튼과 Valid Configuration 표시](/assets/blog/guide/vercel-domain-setup-2026/17.png)

**주황색 경고가 남아 있어도 괜찮은 경우가 있어요.** 사이트가 정상으로 열리는데 `DNS Change Recommended`가 보인다면, 연결은 되어 있고 Vercel이 더 새로운 IP로 바꾸기를 권하는 상태예요. 급하지 않습니다. 위 캡처에서도 제 도메인은 주황색이고, 파란 체크는 `.vercel.app` 주소에만 붙어 있어요.

- 브라우저 주소창에 도메인을 입력해 보세요.
- 사이트가 뜨고 주소창 왼쪽에 **사이트 정보 아이콘**이 보이면 끝난 거예요.

![브라우저 주소창 - 사이트 정보 아이콘](/assets/blog/guide/vercel-domain-setup-2026/18.png)

*위 이미지는 주소창 부분을 재현해 만든 것입니다. 안쪽 페이지는 실제 화면이에요.*

**예전 글에서 말하는 "자물쇠"를 찾지 마세요.** 크롬 117부터 자물쇠가 사라지고 슬라이더 모양 아이콘으로 바뀌었어요. 그 아이콘을 누르면 연결이 안전한지 확인할 수 있습니다. 보안 인증서(HTTPS)는 Vercel이 자동으로 발급해 줍니다.

## 아직 연결이 안 됐다면?

| 증상 | 해결 |
|---|---|
| 10분이 지났는데 그대로 | 정상이에요. 최대 24시간에서 48시간까지 걸릴 수 있어요. |
| 하루가 지나도 그대로 | 가비아 DNS 관리를 다시 열어 IP 숫자에 오타가 없는지 확인해요. |
| 사이트는 뜨는데 옛날 화면 | 브라우저 캐시예요. 시크릿 창으로 열어 보세요. |
| 주황색 경고만 남음 | 사이트가 열린다면 연결된 거예요. 급하지 않습니다. |

## 이메일을 쓰고 있어도 괜찮아요

- A 레코드 한 줄만 더하는 방식이라 기존 설정은 그대로 살아 있어요.
- 네임서버를 통째로 바꾸는 방식이었다면 메일이 끊길 수 있는데, 오늘은 그걸 하지 않았습니다.
- 혹시 메일 관련 레코드를 실수로 지우지만 않으면 됩니다.

# 가비아가 아닌 곳에서 샀다면

괜찮아요. 역할은 똑같아요.

- 호스팅케이알, 카페24, 후이즈 등 어디서 샀든 그 사이트가 "가비아 역할"을 해요.
- 그 사이트에서 **DNS 관리** 또는 **DNS 레코드 설정** 메뉴만 찾으면 됩니다.
- 넣는 값은 2부에서 받은 A 레코드 한 줄로 똑같아요.
- 클라우드플레어에서 산 도메인도 같은 방식이에요. 다만 레코드의 구름 아이콘을 회색(DNS only)으로 꺼 두어야 합니다.

# 마치며

오늘 한 일을 정리해 볼게요.

1. **가비아**에서 도메인을 샀어요.
2. **Vercel**에 도메인을 등록하고 A 레코드 값을 받았어요.
3. **가비아** DNS 관리에 그 값을 적었어요.
4. **Vercel**에서 연결을 확인했어요.

가비아는 주소록, Vercel은 목적지. 이것만 기억하면 다음부터는 5분 만에 끝나요.

**놓치기 쉬운 한 가지**

- 도메인은 매년 갱신해야 해요.
- My가비아에서 **자동 연장**을 켜 두면 안전해요.
- 만료되면 사이트가 통째로 사라지니 꼭 확인해 주세요.
