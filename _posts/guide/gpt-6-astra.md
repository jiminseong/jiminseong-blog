2026년 9월 3일, OpenAI가 GPT-6 Astra를 내놨어요. "세계에서 가장 똑똑하고 가장 잘 정렬된 모델"이라는 문장으로 시작하는 발표문이었죠.

이 글은 그 주장을 그대로 옮기는 글이 아니에요. 공식 발표문과 안전 정책 페이지를 원문으로 읽고, OpenAI가 아닌 곳에서 매긴 점수도 같이 놓고, **비개발자에게 실제로 무엇이 달라지는지**만 추렸습니다.

- 무엇이 달라졌는지 세 가지로 정리해요.
- 숫자는 OpenAI 것과 독립 기관 것을 나란히 둡니다.
- 왜 일부 기능은 막혀 있는지, 어디서 쓸 수 있는지, 돈은 얼마나 드는지 적어요.

이 글의 주소는 `jiminseong.com/guide/gpt-6-astra` 입니다. 저는 GPT 유료 구독이 없어서 실제 사용 화면은 없어요. 대신 인용은 전부 공식 페이지 원문에서 가져왔습니다.

# Astra가 뭔가요?

먼저 헷갈리는 것부터 정리할게요. **Astra는 앱이 아니라 모델이에요.**

- ChatGPT는 앱이에요. 우리가 대화하는 화면이죠.
- Astra는 그 안에서 답을 만드는 두뇌예요. 전에는 GPT-5.6 Sol이었고, 이제 Astra가 들어갔어요.
- 그래서 "Astra를 쓴다"는 말은 ChatGPT, Codex, 또는 다른 앱에서 모델로 Astra를 고른다는 뜻이에요.

비유하면 자동차와 엔진이에요. 차는 그대로인데 엔진이 바뀐 겁니다. 그래서 "뭐가 달라졌나"는 곧 "이 엔진이 전 엔진보다 뭘 더 하나"라는 질문이에요.

![OpenAI 발표문 첫 화면](/assets/blog/guide/gpt-6-astra/AT-01.png)

# 달라진 것 세 가지

발표문은 길지만 비개발자에게 와닿는 변화는 셋으로 묶여요.

## 1. 컴퓨터를 직접 씁니다

OpenAI가 가장 앞에 내세운 게 이거예요. 원문 제목이 "The world's best computer use model"입니다.

말로만 답하는 게 아니라 화면을 보고 클릭하고 입력해요. 발표문이 든 예시는 이래요.

- 온라인 양식 채우기
- 고객 관리 프로그램에 기록 업데이트하기
- 달력 정리하기
- 조사해서 메일이나 문서에 요약 써 넣기
- 웹사이트 만들고, 버튼이 다 작동하는지 직접 눌러 보기
- 소프트웨어 설치하고 테스트하고, 화면에 뜬 오류 해결하기

전 모델도 비슷한 걸 했지만 속도와 정확도가 달라졌다고 해요. 컴퓨터 사용 벤치마크에서 같은 점수대 작업을 **전 모델의 절반 정도 시간**에 끝냈다는 게 OpenAI의 설명이에요. 약 40분 걸릴 일을 전 모델은 약 75분 걸렸다고 적혀 있습니다.

## 2. 문서, 발표 자료, 설계 같은 전문 작업

두 번째는 "A step change in professional work"예요.

- 회사 양식에 맞춰 문서, 슬라이드, 스프레드시트를 만들어요. 발표문 표현으로는 "기존 템플릿을 지키고, 핵심만 담아 잘 배치된 슬라이드"를 만드는 데 가장 좋은 모델이에요.
- 필요한 맥락만 골라 넣도록 따로 훈련했다고 해요. 불필요한 내용을 반복해서 붙여 넣지 않는다는 뜻이에요.
- 회로 기판 설계, 3D 모델링, 게임 제작 같은 전문 도구도 직접 다뤄요. 발표문에는 Blender로 집을 만들고 Unreal Engine 5에서 걸어 다닐 수 있는 장면으로 바꾸는 영상이 있어요.
- ChatGPT 안의 Sites 기능으로 웹사이트를 만들고 바로 올려서 공유할 수 있어요.

## 3. 애매하면 묻고, 아니면 알아서 갑니다

세 번째가 저는 제일 실용적이라고 봐요. 판단력 얘기예요.

발표문 원문을 옮기면 이래요. "지시가 해석의 여지를 남길 때, 맥락으로 일상적인 빈틈을 채우고, 답에 따라 결과가 달라질 때만 집중된 질문을 한다." 답을 안 하면 합리적인 가정으로 진행하되, 중요한 결정은 기다린다고요.

또 하나. 작업 중간에 "이것도 해 줘"라고 끼어들면 전 모델은 원래 목표를 잊어버리는 일이 있었는데, Astra는 새 요구를 더하면서 원래 작업을 놓치지 않는다고 해요.

이게 왜 중요하냐면, 컴퓨터를 대신 쓰는 도구는 **어디서 멈추고 물어보느냐**가 신뢰의 전부이기 때문이에요. 결제 직전에 물어보는 도구와 그냥 눌러 버리는 도구는 완전히 다른 물건이죠.

# 숫자로 보면 어떤가요

OpenAI 발표문에는 벤치마크 표가 아홉 개 있어요. 그중 이 글의 주제와 닿는 것만 뽑았습니다.

![발표문의 벤치마크 표](/assets/blog/guide/gpt-6-astra/AT-02.png)

| 분야 | 벤치마크 | Astra | 전 모델 (GPT-5.6 Sol) | 비교 대상 최고 |
|---|---|---|---|---|
| 컴퓨터 사용 | Agents' Last Exam | 59.3% | 53.6% | 55.5% (Claude Opus 5) |
| 컴퓨터 사용 | OSWorld 2.0 | 72.6% | 65.7% | 70.2% (Claude Opus 5) |
| 코딩 | Terminal-Bench 4.0 | 57.9% | 37.3% | 55.8% (Claude Fable 5.1) |
| 전문 작업 | BenchCAD (3D 설계) | 95.9% | 83.3% | 84.3% (Claude Fable 5.1) |
| 과학 | GPQA Diamond | 96.0% | 94.6% | 95.3% (Gemini 3.8 Flash) |

이 표는 OpenAI가 직접 돌린 결과예요. 그래서 **OpenAI가 아닌 곳의 점수**도 같이 봐야 공정합니다. 두 곳을 확인했어요.

| 독립 지표 | 무엇을 재나 | Astra 순위 | 1위 |
|---|---|---|---|
| Vals Index (2026-09-10) | 금융·코딩·법률 실무 과제를 GDP 비중으로 가중 | 3위, 66.61% | Claude Fable 5.1, 68.83% |
| Artificial Analysis Intelligence Index v4.3 | 평가 10종 종합 | 공동 3위, 53점 | Claude Fable 5.1, 53점 |

그리고 흥미로운 게 하나 있어요. OpenAI 발표문의 표 자체에도 Astra가 뒤지는 항목이 실려 있습니다. Artificial Analysis 지수(당시 v4.1.1)에서 Astra 61.2 대 Claude Fable 5.1 65.7, 그리고 Humanity's Last Exam에서 Astra 57.2% 대 Claude 65.0%예요.

정리하면 이래요.

- **컴퓨터를 직접 쓰는 일과 코딩, 3D 설계에서는 Astra가 앞서요.** 이건 OpenAI 표와 독립 지표가 대체로 일치합니다.
- **종합 지능 점수에서는 1위가 아니에요.** 독립 지표 두 곳 모두 3위이고, OpenAI 표에도 그렇게 적혀 있어요.
- "세계에서 가장 똑똑한 모델"이라는 첫 문장은 **어느 벤치마크를 보느냐에 따라 맞기도 틀리기도 해요.** 컴퓨터 사용 기준이면 맞고, 종합 기준이면 아닙니다.

# 왜 일부 기능은 막혀 있나요

Astra 발표에서 가장 이례적인 부분이에요. OpenAI 스스로 이 모델을 **위험 등급 Critical**로 분류했습니다. 이 등급을 받은 첫 모델이에요.

무슨 뜻인지 안전 정책 페이지 원문을 옮기면 이래요. "적절한 도구와 접근 권한이 있으면, 사람이 한 단계씩 지시하지 않아도 잘 보호된 여러 시스템에서 알려지지 않은 보안 결함을 찾고 그걸 악용하는 방법을 개발할 수 있다."

쉽게 말해 **해킹을 너무 잘해서** 아무에게나 다 열어 줄 수 없다는 뜻이에요. 그래서 이렇게 조치했어요.

- 위험한 보안 요청을 거부하도록 훈련했어요. 우회 시도 테스트에서 91.5%를 거부했고, 전 모델은 59%였다고 해요.
- 지금 나온 버전은 보안 코드 검토나 패치 같은 방어 작업은 하지만, 취약점을 실제로 뚫는 코드를 만들어 달라는 요청은 거부해요.
- 고급 보안 기능은 소수의 테스터에게만 먼저 열고, Daybreak Blue라는 프로그램을 통해 방어 목적 사용자에게 점차 넓힌다고 해요.
- 모델의 추론과 행동을 감시하는 시스템이 돌아가요. 이게 작업을 멈추면 ChatGPT나 Codex에서는 사용자에게 확인을 물어보고, API에서는 그냥 멈춥니다.

일반 사용자가 체감할 부분은 마지막이에요. 발표문도 "정당한 작업이 느려지거나 멈출 수 있다"고 인정하고 있어요. 뭔가 하다가 갑자기 확인을 물어보면 이 감시 장치가 작동한 거예요.

# 어디서 쓸 수 있나요

## ChatGPT 요금제

![ChatGPT 요금제 비교표의 GPT-6 Astra 행](/assets/blog/guide/gpt-6-astra/AT-03.png)

| 플랜 | Astra |
|---|---|
| Free | 안 됨 |
| Go | 안 됨 |
| Plus | 제한적 |
| Pro | 한도 확장, 5배 사용량, Astra Pro 포함 |
| Business / Enterprise | 유연. 관리자가 켜야 하고 기본은 꺼짐 |

Plus 요금제 카드에는 "GPT-5.6 기반의 고급 추론"이라고만 적혀 있고 Astra는 비교표에만 "제한적"으로 나와요. Plus로 Astra를 제대로 쓰려는 분은 이 점을 미리 알아 두세요.

## 개발자 API

- 모델 이름은 `gpt-6-astra`예요. Azure와 AWS Bedrock에서도 됩니다.
- 가격은 입력 100만 토큰당 10달러, 출력 100만 토큰당 50달러예요.
- 두 배 빠른 Fast 모드는 두 배 값이에요.

## Aside 같은 AI 브라우저

[앞선 글](/guide/aside-browser-setup)에서 "Aside 모델 목록에 Astra가 보이면 그걸 고르세요"라고 썼는데, 확인해 보니 **2026년 9월 13일 기준 아직 없어요.** 설치된 Aside의 모델 목록에는 GPT-5.6 계열과 Claude, Gemini만 있습니다. 들어오면 Settings > Models > Task models에서 고르면 돼요. Aside 글의 해당 문장도 고쳐 두었습니다.

# 토큰 아끼는 법, ChatGPT와 Codex를 나눠 쓰기

Astra는 사용량 제한이 있는 모델이에요. 발표문에는 "기존 구독 한도 안에 포함되고, 추가 사용량은 크레딧으로 살 수 있다"고 적혀 있어요. 그래서 한도를 아끼는 방법이 있으면 좋겠죠.

OpenAI 도움말을 보면 **Codex와 일반 대화는 사용량 풀이 달라요.** 원문은 이래요. "Codex, ChatGPT Work, ChatGPT for Excel, Workspace Agents는 하나의 공유 한도와 크레딧 풀을 쓴다." 그리고 "일반 대화의 음성은 별도 한도가 있고 Codex 사용량을 소모하지 않는다." Codex 쪽은 5시간 단위와 주 단위 창으로 따로 관리돼요.

그러니 일을 둘로 나누면 한쪽 한도만 태우지 않아요.

- **ChatGPT 대화**에는 범용 작업을 맡겨요. 브레인스토밍, 분석된 데이터에서 인사이트 뽑기. 웹사이트로 치면 어떤 페이지가 필요하고 각 페이지에 무슨 문구를 넣을지 정하는 일이에요.
- **Codex**에는 파일이 실제로 바뀌는 작업을 맡겨요. 코딩, 그리고 배포하고 테스트하고 오류 잡는 일처럼 결과가 컴퓨터에 남는 일이에요.

두 개를 오갈 때 주의할 점이 둘 있어요.

1. **형식을 고정하세요.** Codex에서 나온 결과를 대화 쪽에 붙여 넣을 때, 그리고 대화에서 정리한 걸 Codex에 보낼 때, 양쪽 다 정해진 틀로 주고받아요. 매번 다르게 쓰면 앞뒤가 안 맞기 시작해요.
2. **맥락이 새는 걸 막으세요.** 두 도구는 서로의 대화를 모릅니다. 그래서 할루시네이션이 생기기 쉬워요. 처음 세션을 열 때 대화 쪽에 이렇게 정해 두세요. "Codex는 항상 새 세션을 여는 걸 기준으로 한다. 따라서 Codex에 보낼 내용에는 기존 맥락을 항상 함께 넣어 달라."

# 한계와 비판

공정하게 반대편도 적어 둘게요.

- **추론 과정이 덜 보여요.** OpenAI가 발표문에 직접 썼어요. "Astra의 서면 추론은 전 모델보다 모니터링하기 어렵다"고요. 더 적은 단계로 문제를 풀 수 있게 되면서 생긴 부작용이고, "심각하게 받아들인다"고 적혀 있습니다. AI 안전 연구자들이 가장 우려하는 지점이에요.
- **종합 지능 1위는 아니에요.** 위에서 본 대로 독립 지표 두 곳 모두 3위입니다.
- **Plus에서는 제한적이에요.** 제대로 쓰려면 Pro예요.
- **안전 장치가 정당한 작업도 멈출 수 있어요.** OpenAI가 스스로 인정한 부분이에요.

# 마치며

정리하면 이래요.

1. Astra는 앱이 아니라 엔진이에요. ChatGPT, Codex, 다른 도구 안에서 골라 씁니다.
2. 컴퓨터를 직접 쓰는 일, 문서와 설계 작업, 그리고 "언제 물어볼지" 판단이 좋아졌어요.
3. 컴퓨터 사용과 코딩에서는 1위, 종합 점수에서는 3위예요.
4. 해킹 능력 때문에 위험 등급이 붙었고, 그래서 일부 기능이 막혀 있어요.
5. Plus는 제한적, Pro부터 제대로예요. Aside에는 아직 안 들어왔어요.

맥에서 Aside를 쓰는 분은 [Aside 가이드](/guide/aside-browser-setup)를, 도메인을 연결하려는 분은 [가비아 가이드](/guide/vercel-domain-setup)를 이어서 보시면 돼요.
